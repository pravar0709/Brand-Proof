1. What BrandProof Does

Organisations maintain brand guidelines, a Claim Ledger (approved facts with evidence, allowed wording, and expiry dates), and a banned/preferred term list. A content creator submits a marketing draft. BrandProof checks every claim against all three sources, returns findings that cite the exact guideline rule or Ledger entry (quoted text), explain why, give a confidence label, and suggest an intent-preserving rewrite.

Creators accept, edit, or dispute each finding — nothing is auto-applied. A reviewer then approves or requests changes.

Core Principle — Cite or Abstain: If no supporting source exists, or the AI's quoted evidence isn't literally in the source text, the finding is marked "Unverified: needs human review." BrandProof never guesses.

2. Completed Features

Core Workflow (End-to-End)

  • One-click demo login (Creator / Manager / Reviewer) — no signup needed
  • Submit drafts via text input or DOCX file upload
  • Automated review pipeline: 6 deterministic checks + optional AI verification
  • 9+ findings per sample draft with severity badges, source citations, and suggestions
  • Accept / Edit / Dispute each finding with reasons
  • Reviewer queue: review findings, Approve or Request Changes
  • Approval blocks if findings are pending (override requires logged reason)
  • Version history: resubmit creates new version, old findings preserved

  • TF-IDF retrieval (scikit-learn) — finds top-3 relevant rules/ledger per segment

  • Text redaction — emails, phones, confidential terms masked before LLM
  • Quote verification — AI's cited evidence verified as literal substring of source
  • Graceful fallback — deterministic checks always work; banner shown if AI unavailable
  • AI badge on every AI-generated finding

5. Three Round 3 Improvements

1. Calibrated Two-Verifier Agreement

Build a labelled benchmark of ~150 (claim, source, expected_verdict) tuples. Compare deterministic checker vs LLM verifier vs combined agreement. Measure false-"Supported" rate and use disagreement signals for calibrated confidence scoring. Moves from heuristic to data-driven, measurable accuracy.

2. Guideline Clarity Analytics

Cluster disputed findings by rule code to identify which brand guidelines generate the most disputes (likely ambiguous or poorly worded). Surface recommendations to managers to clarify rule text. Creates a feedback loop: the system gets smarter from usage data and helps orgs improve their own guidelines.

3. Privacy-First Enhanced Disclosure & Compliance Reports

Add per-finding redaction visibility (show what was masked before LLM), browsable audit log in UI, Ledger-expiry alert dashboard with notifications, and exportable compliance reports (PDF/CSV). Addresses enterprise trust and regulatory requirements for real-world deployment.
